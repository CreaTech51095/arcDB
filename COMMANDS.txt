===========================================
COPY-PASTE COMMANDS FOR arcDB SETUP
===========================================

📌 STEP 1: PUSH TO GITHUB
--------------------------
git add .
git commit -m "Configure for arcDB and arcdb.web.app"
git remote remove origin
git remote add origin https://github.com/CreaTech51095/arcDB.git
git push -u origin main


📌 STEP 2: CREATE FIREBASE PROJECT
----------------------------------
Go to: https://console.firebase.google.com
Email: createch51095@gmail.com
Project ID: arcdb (EXACTLY this name)


📌 STEP 3: INSTALL DEPENDENCIES
-------------------------------
cd firebase-functions
npm install
cd ..
cd frontend
npm install
cd ..


📌 STEP 4: LOGIN TO FIREBASE
----------------------------
firebase login


📌 STEP 5: BUILD FRONTEND
-------------------------
cd frontend
npm run build
cd ..


📌 STEP 6: DEPLOY TO FIREBASE
-----------------------------
firebase deploy


📌 ALTERNATIVE: RUN AUTOMATED SCRIPT
------------------------------------
Windows PowerShell:
    .\setup-arcdb.ps1

Mac/Linux/Git Bash:
    chmod +x setup-arcdb.sh
    ./setup-arcdb.sh


📌 CREATE ADMIN USER (AFTER DEPLOYMENT)
---------------------------------------
1. Visit https://arcdb.web.app
2. Register an account
3. Download service account key from Firebase Console
4. Save as: arcdb-firebase-adminsdk.json
5. Run:
   node update-user-role.js your-email@example.com admin


📌 IMPORTANT LINKS
------------------
Live App:          https://arcdb.web.app
GitHub:            https://github.com/CreaTech51095/arcDB
Firebase Console:  https://console.firebase.google.com/project/arcdb


📌 FIREBASE CONFIGURATION
-------------------------
After creating Firebase project, create this file:
frontend/.env

With this content (replace with your actual values):
VITE_FIREBASE_API_KEY=your_api_key_here
VITE_FIREBASE_AUTH_DOMAIN=arcdb.firebaseapp.com
VITE_FIREBASE_PROJECT_ID=arcdb
VITE_FIREBASE_STORAGE_BUCKET=arcdb.appspot.com
VITE_FIREBASE_MESSAGING_SENDER_ID=your_sender_id_here
VITE_FIREBASE_APP_ID=your_app_id_here
VITE_FIREBASE_MEASUREMENT_ID=your_measurement_id_here


📌 ENABLE FIREBASE SERVICES
---------------------------
Authentication:
  - Go to Build > Authentication
  - Enable Email/Password provider

Firestore:
  - Go to Build > Firestore Database
  - Create database in production mode

Storage:
  - Go to Build > Storage
  - Get started with default rules


📌 TROUBLESHOOTING
------------------
Error: "Project ID mismatch"
  → Run: firebase use arcdb

Error: "Permission denied"
  → Run: firebase login --reauth

Build errors:
  → Delete node_modules and reinstall
  → cd frontend && rm -rf node_modules && npm install
